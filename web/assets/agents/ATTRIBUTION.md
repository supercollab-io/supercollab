# Agent logo sources

Every mark in this directory is a self-hosted copy of an official product asset. The machine-readable source URL and SHA-256 for each file are recorded in `SOURCES.json` and checked by `npm run check`.

| Local asset | Official source |
| --- | --- |
| `claude-code.png` | Claude Code documentation favicon from `code.claude.com` |
| `codex.png` | Icon shipped by OpenAI's verified Codex extension on the Visual Studio Marketplace, version `26.5721.30844` |
| `gemini-cli.png` | Gemini CLI IDE companion icon from `google-gemini/gemini-cli` |
| `opencode.svg` | OpenCode dark square brand mark from `anomalyco/opencode` |
| `copilot.svg` | GitHub Copilot mark from GitHub Primer Octicons |
| `cline.png` | Dark app icon from Cline's official downloadable brand kit |
| `cursor.png` | Default dark 2.5D app icon from Cursor's official downloadable brand kit |
| `factory-droid.svg` | Factory's official website favicon |
